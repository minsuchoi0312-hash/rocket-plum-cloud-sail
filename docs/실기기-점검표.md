# 실기기 점검표

에뮬레이터와 단위 테스트로는 확인할 수 없어서, **실제 프린터로 한 번씩 뽑아 봐야 하는 것**만 모았어요.
결과는 칸에 ✅ / ❌ 로 적고, ❌ 이면 기종 이름 · 증상 · 사진을 남겨 주세요.

## 준비

- 폰과 프린터를 같은 와이파이에 두기 (USB 는 OTG 선)
- 시험 문서 3개
  - **A**: 1~5쪽에 큰 숫자가 찍힌 5쪽 PDF (앞뒤 짝, 방향 확인용)
  - **B**: 컬러 사진 1장
  - **C**: 글자만 있는 1쪽 메모
- 인쇄 화면의 '팩' 이름을 적어 두기 (표준 · 레이저 · 엡손 · 삼성 · HP 잉크젯 · 캐논 · 전용 방식)

## 1. 수동 양면 (자동 양면이 없는 팩 전부)

| 확인 | 방법 | 기대 결과 | 결과 |
|---|---|---|---|
| 앞면 | A 를 양면(긴 쪽)으로 인쇄 | 1 · 3 · 5쪽만 나오고 '수동 양면 · 뒷면 차례예요' 안내가 뜸 | |
| 뒷면 | 안내대로 뭉치를 뒤집어 넣고 '뒷면 인쇄' | 2 · 4쪽 + 빈 쪽 1장. 1 뒤에 2, 3 뒤에 4 | |
| 방향 | 책처럼 넘겨 보기 | 앞 · 뒤 글자 방향이 같음 | |
| 짧은 쪽 | A 를 양면(짧은 쪽)으로 | 달력처럼 위로 넘기면 바로 읽힘 | |
| 거꾸로 끄기 | '뒷면을 거꾸로 보내기' 끄고 다시 | 레이저(뒷면이 아래로 나오는 기종)에서 순서가 맞음 | |

## 확인되지 않은 부분 (알아 두기)

- 삼성 초기 SCX(0x0D 압축)와 CLP-500 계열 컬러 띠는 공개 자료로 만든 것이라 **실기기 확인 전까지는 시험 기능**이에요.
- 캐논 A6 외 사진 용지 크기(4×6 · 5×7 · 8×10)는 코드가 확실하지 않아 넣지 않았어요.
- 엡손 Stylus 옛 기종(ESC/P2), 캐논 신형 명령 체계(ESC (P 8 · 9바이트) 기종은 아직 '준비 중'이에요.
