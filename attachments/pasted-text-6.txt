지금 만든 `office_print` Flutter 앱을 실제 갤럭시탭·아이폰과 사무실 복사기에서 바로 쓸 수 있게 아래 4가지를 마감해 줘.

1. 암호 걸린 PDF 실제 해제 지원 (반쪽짜리 입력창 완성)
- 지금 `pdfx`는 안드로이드 `PdfRenderer` 한계로 비밀번호 입력창이 있어도 실제로 암호 PDF를 못 열어.
- PDFium 기반인 `pdfrx`로 PDF 렌더러를 교체해서, 안드로이드와 iOS 모두 열기 비밀번호가 걸린 PDF(은행·관공서·계약서)를 입력창으로 실제로 열고 미리보기·PCL5e 인쇄까지 되게 해 줘.
- 교체 후에도 가로 PDF 자동 90도 회전, 72px 여백 맞춤, 쪽 넘김 경합 취소, 페이지 비트맵 즉시 해제가 그대로 유지되게 해 줘.

2. 와이파이 복사기 자동 모델·언어 확인 (`@PJL INFO ID`)
- 1단계에서 mDNS로 찾았거나 IP를 직접 입력해 연결 테스트(TCP 9100)를 할 때, 소켓 연결만 보지 말고 짧은 PJL 조회(`ESC%-12345X@PJL INFO ID\r\nESC%-12345X`, 2초 타임아웃)를 보내 복사기 모델명을 자동으로 읽어 와 줘.
- 응답이 오면 모델명을 자동으로 채우고, 응답이 없는 기종이면 기존처럼 수동 확인(2단계)이나 바로 인쇄로 자연스럽게 넘어가게 해 줘.

3. 인쇄 중 화면 꺼짐 방지 (`wakelock_plus`)
- 갤럭시탭에서 20~50쪽 PDF를 300dpi로 변환해 보내는 도중 화면이 꺼지면 와이파이 소켓이나 USB 연결이 끊길 수 있어.
- `sending == true`인 동안 화면이 꺼지지 않게 잠금(wakelock)을 켜고, 인쇄 완료·취소·오류 시 `finally`에서 반드시 해제해 줘.

4. 실사용 마감 및 APK 빌드 검증
- 앱 표시 이름을 `바로 인쇄`로 통일하고(Android `AndroidManifest.xml`, iOS `Info.plist`), 기본 Flutter 아이콘 대신 `#1b2a45` 배경의 깔끔한 인쇄 앱 아이콘으로 교체해 줘.
- 수정 후 아래 3가지를 모두 통과시키고 결과를 보고해 줘:
  1) `flutter analyze` 에러·경고 0건
  2) `flutter test` 전체 통과
  3) `flutter build apk --debug` 성공 및 생성된 APK 경로 확인
