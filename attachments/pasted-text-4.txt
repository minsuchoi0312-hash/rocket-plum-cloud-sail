1차 패치에 이어 남은 안정화·메모리·테스트 항목(#5, #6, #15, #22~#30)을 2차 패치로 마무리해 줘.

1. PDF 쪽 넘김 경합 제거 (#5)
- 미리보기 렌더링 시 이전 `renderTask.cancel()`을 호출하고 요청 ID 토큰을 비교해서, `< 이전 / 다음 >`을 빠르게 연타해도 pdf.js 충돌이나 오래된 쪽 덮어쓰기가 발생하지 않게 해 줘.

2. OS 인쇄 창 백지(2초 타이머) 및 갤럭시탭 메모리 폭탄 수정 (#22, #23, #28)
- `printSheet()`에서 모바일 백지의 원인인 `setTimeout(cleanup, 2000)`을 제거하고, `afterprint` 이벤트(및 다음 인쇄/언마운트 시점)에서만 정리해 줘.
- 여러 쪽 PDF 인쇄 시 `toDataURL` 문자열 배열 대신 `canvas.toBlob` + `URL.createObjectURL`을 쓰고, 정리 시 `#print-root`의 DOM과 Blob URL을 완전히 비워 줘. (30쪽 초과 대용량 인쇄 창 출력 시 해상도를 단계적으로 낮추거나 쪽 분할 안내를 띄워 탭 크래시 방지)
- 사파리에서 A3/B5 선택 시 "사파리 인쇄 창에서 용지 크기를 한 번 더 확인해 주세요." 안내를 띄워 줘.
- 파일 교체·단계 이탈 시 `#print-root`와 `pdfBytes` 등 민감한 문서 메모리도 즉시 비워 줘.

3. 긴 메모 여러 쪽 분할 (#24)
- `간단 메모`가 1쪽 높이를 넘으면 잘라 버리지 말고, USB PCL5e·OS 인쇄 창·PDF 저장 모두 자동으로 여러 쪽으로 분할해 출력해 줘.

4. 전송 중 UI 잠금 및 예외·이미지 방어 (#15, #26, #27)
- `sending === true`인 동안 파일 입력, 탭 전환, `바꾸기`, 옵션 변경을 모두 비활성화해 전송 중 상태 꼬임을 막아 줘.
- `usePrinterStore.persist.rehydrate()`를 `try/catch`로 감싸 스토리지 차단 브라우저에서도 앱이 멈추지 않게 해 줘.
- 사진 선택 시 HEIC 파일이면 "HEIC 사진은 지원하지 않아요. JPG/PNG로 바꿔서 골라 주세요."라고 안내하고, 초고해상도(예: 4000만 화소 이상) 이미지는 `createImageBitmap` 리사이즈 또는 안전한 오류 안내로 탭 크래시를 막아 줘.

5. 서비스워커 캐시 안전성 및 카탈로그 보수화 (#25, #29)
- `sw.js` 캐시 버전을 올리고, 동적 `import()` 청크 로딩 실패(오프라인 또는 배포 직후 구버전 캐시) 시 하얀 화면 대신 "네트워크에 다시 연결하거나 새로고침해 주세요." 안내가 뜨게 처리해 줘.
- USB `CMD`가 비어 있고 이름만으로 매칭된 복사기(예: PCL 옵션이 없을 수 있는 캐논 iR-ADV 등)는 바로 USB PCL5e로 쏘지 말고 2단계 확인 또는 안전한 안내를 거치게 보수적으로 조정해 줘.

6. 단위 테스트 대폭 보강 (#6, #30)
- 기존 4개 테스트 외에 다음을 검증하는 단위 테스트를 추가해 줘:
  - PackBits 128바이트 반복/비반복 경계, `0x80` 미생성, 끝 1~2바이트, 2바이트 반복
  - PJL `QTY` 단일 사용(`ESC & l n X` 미포함), 홀수 쪽 양면 × 2부 시 빈 뒷면 패딩
  - 완전 빈 페이지에 최소 래스터 존재
  - `ESC * r 1 A`, `S`/`T` 크기 선언, 줄 경계 청킹
  - `/Rotate 90`이 이미 있는 PDF가 180도 뒤집히지 않음
  - IPP-over-USB(`protocol=4`) 제외 및 `CMD` 조합(`PCL,PCLXL` 등) 분기
  - 긴 메모 다쪽 분할
- 모든 단위 테스트와 `npm run build` 통과 결과를 보고해 줘.
