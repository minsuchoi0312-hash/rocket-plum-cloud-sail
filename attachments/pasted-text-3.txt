30개 감사 결과 아주 정확했어. 이제 첫 실기기 테스트에서 종이가 낭비되거나 복사기가 멈추는 치명·높음 항목부터 1차 패치로 한 번에 고쳐 줘. (#1~#4, #7~#14, #17~#21)

[A. USB 인터페이스 선택·통신 복구 (#4, #17, #18, #19, #21)]
1. `discover.ts`에서 프린터 인터페이스를 고를 때 `interfaceClass === 7`이면서 `interfaceProtocol === 2`(양방향) → `1`(단방향) 순으로만 선택해 줘. `interfaceProtocol === 4`(IPP-over-USB)와 `3`(1284.4), 클래스 255 스캐너는 프린터 후보에서 제외해 줘.
2. `GET_DEVICE_ID`의 `wIndex`가 인터페이스 0이 아닐 때 실패하지 않도록 `(interfaceNumber << 8) | alternateSetting`을 먼저 시도하고 실패 시 `interfaceNumber`로 폴백해 줘.
3. `sendUsbBytes`에서 `result.bytesWritten < chunk.byteLength`인 부분 전송을 감지해 남은 바이트를 이어 보내고, `stall`이면 `clearHalt("out")` 후 재시도해 줘.
4. 15초 타임아웃이나 치명적 전송 오류가 나면 `clearHalt("out")` + `releaseInterface` + `close`를 시도하고 `sessions`에서 해당 장치를 제거해 다음 인쇄가 먹통이 되지 않게 해 줘. 정상 작업 완료 후에도 인터페이스를 적절히 정리하거나 재사용 상태를 명확히 하고, `navigator.usb`의 `connect` 이벤트도 감지해 줘. 시리얼이 없는 기기는 객체 참조(WeakMap ID 등)로 구분해 줘.

[B. PCL5e · PJL · PDF Direct 프로토콜 정밀 수정 (#1, #2, #3, #7, #8, #9, #10, #11, #20)]
5. 장수 이중 전송 제거: `pclJobHeader`에서 `ESC & l n X`를 삭제하고 PJL 장수만 사용해 줘. 단, 여러 쪽 문서는 부수 묶음(1-2-3, 1-2-3)을 위해 `@PJL SET QTY=n`(1쪽일 때는 `@PJL SET COPIES=n`)을 보내 줘.
6. 홀수 쪽 양면 × 2부 이상일 때 1부 마지막 쪽 뒷면에 2부 1쪽이 찍히지 않도록, 총 출력 쪽수가 홀수이고 양면이 켜져 있으면 마지막에 확정 빈 페이지를 1쪽 패딩해 줘.
7. 완전 빈 페이지가 복합기의 "빈 페이지 절약"에 삼켜져 양면이 밀리지 않도록, 잉크가 0인 빈 쪽도 모서리(우하단 끝 1픽셀)에 보이지 않는 최소 래스터 1줄을 찍어 페이지 존재를 확정해 줘.
8. 여백·원점·래스터 크기 선언: `ESC * r 0 A` 대신 커서 기준인 `ESC * r 1 A`를 쓰고, 매 페이지 `ESC * r <폭px> S`, `ESC * r <높이px> T`를 선언해 줘. `ESC * p 0 x 0 Y` 기준으로 왼쪽·위쪽이 잘리거나 이중 여백이 생기지 않게 좌표와 인쇄 영역 크기를 일치시켜 줘.
9. 가로 PDF 회전 버그 수정: 이미 `/Rotate 90` 등이 걸려 있는 PDF가 `page.rotate + 90`으로 180도 뒤집히지 않도록, `page.getViewport({ scale: 1 })`의 최종 표시 크기(`width > height`)를 기준으로만 90도 회전을 적용해 줘.
10. 취소 시 `ESC * b <n> W` 중간 끊김 방지: PCL5e 페이지 바이트를 4KB 임의 슬라이스하지 말고, 항상 완전한 `W` 행(또는 명령) 경계 단위로 ~4KB 청크를 묶어 전송해 줘. 취소 시 현재 명령 경계에서 멈춘 뒤 `ESC * r C` + `ESC E` + UEL + `@PJL EOJ` + UEL을 보내 복사기가 멈추지 않게 해 줘.
11. `CMD` 판정 강화 및 PDF Direct 가드: `CMD`에 `PCL,PCLXL`이나 `PCL,SPL`이 섞여 있을 때 맨 `PCL`만으로 PCL5e를 단정하지 말고 명확한 `PCL5/PCL5e/PCL5c`가 있을 때만 자동 PCL5e 직송해 줘. PDF Direct는 암호 없음 + 전체 쪽 + 컬러 + 25MB 이하일 때만 허용하고 초과·암호 시 PCL 래스터 또는 인쇄 창으로 내려 줘.

[C. 한국 사무실 PDF 완벽 렌더링 (#12, #13, #14)]
12. `pdfjs-dist`의 `cmaps/`와 `standard_fonts/`를 빌드 산출물(예: `public/pdfjs/`)에 로컬 포함시키고, `openPdf()`의 `getDocument()`에 `cMapUrl`, `cMapPacked: true`, `standardFontDataUrl`을 연결해서 한글 비임베디드 공문·은행 PDF가 백지로 나오지 않게 해 줘.
13. `renderPdfPage()`에 `annotationMode: AnnotationMode.ENABLE_FORMS`를 적용해 도장·체크박스·폼 입력값이 인쇄물에서 빠지지 않게 해 줘.
14. 암호 PDF 처리: 열기 암호(PasswordException)가 걸린 PDF면 화면에 비밀번호 입력칸을 띄워 열 수 있게 하고, 소유자 암호(편집/복사 제한만 있는 관공서 PDF)는 `slicePdf`에서 `PDFDocument.load(data, { ignoreEncryption: true })`로 처리하며 USB PDF Direct 전송은 막고 PCL/인쇄 창으로 보내 줘.

1차 패치 후 `npm run build` 통과 여부와 변경된 핵심 바이트·경로 동작을 요약해 줘.
