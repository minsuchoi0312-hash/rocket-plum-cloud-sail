1차 패치 아주 깔끔하게 됐어. 방금 반영한 부분의 미세 보완 3가지와, 아까 감사에서 남은 안정화·메모리·테스트 항목(#5, #6, #15, #22~#30)을 2차 패치로 한 번에 마감해 줘.

[A. 1차 패치 미세 보완 3가지]
1. PCL5e 세로 원점 72px 보정: `ESC & l 0 E` 상태에서는 가로 `0 X`만 논리 좌측 여백(~71px)이고 세로 `0 Y`는 종이 물리 상단 끝이라 위쪽이 잘릴 수 있어. 이미 사방 72px를 줄여 그린 영역을 정중앙에 맞추려면 매 페이지 커서를 `ESC * p 0 x 72 Y`로 바꿔 줘.
2. 타임아웃·오류 시 USB 정리 보장: `clearHalt("out")`, `releaseInterface()`, `close()`를 각각 개별 `try/catch`로 감싸 앞 단계가 예외를 내도 반드시 `close()`와 `sessions` 삭제까지 끝나게 해 줘.
3. `/pdfjs/` 경로 및 서빙 확인: `cMapUrl`과 `standardFontDataUrl` 끝이 `/`로 끝나는지 확인하고, 빌드 프리뷰에서 `/pdfjs/cmaps/Adobe-Korea1-UCS2.bcmap` 같은 파일이 HTML 폴백이 아니라 실제 바이너리(200 OK)로 응답하는지 확인해 줘.

[B. 갤럭시탭 안정화 · 예외 방어 (#5, #15, #22~#29)]
4. PDF 쪽 넘김 경합 제거 (#5): 미리보기 렌더 전 이전 `renderTask.cancel()`을 호출하고 요청 ID 토큰을 비교해서, `< 이전 / 다음 >`을 빠르게 연타해도 pdf.js 충돌이나 오래된 쪽 덮어쓰기가 나지 않게 해 줘.
5. OS 인쇄 창 2초 백지 제거 및 갤럭시탭 메모리 폭탄 해결 (#22, #23, #28):
- `printSheet()`에서 모바일 백지 원인인 `setTimeout(cleanup, 2000)`을 없애고 `afterprint` 이벤트(및 다음 인쇄 시작/언마운트 시점)에서만 정리해 줘.
- 여러 쪽 PDF 인쇄 시 `toDataURL` 문자열 배열 대신 `canvas.toBlob` + `URL.createObjectURL`을 쓰고, 정리 시 `#print-root` DOM과 Blob URL을 전부 해제해 줘. 30쪽 초과 인쇄 창 출력 시에는 해상도를 낮추거나 쪽 분할 안내를 띄워 탭 강제 종료를 막아 줘.
- 사파리에서 A3/B5 선택 시 "사파리 인쇄 창에서 용지 크기를 한 번 더 확인해 주세요." 안내를 띄워 줘.
- 파일 교체나 단계 이탈 시 `#print-root`와 `pdfBytes` 메모리도 즉시 비워 줘.
6. 긴 메모 여러 쪽 자동 분할 (#24): `간단 메모`가 1쪽 높이를 넘으면 자르지 말고 USB PCL5e·OS 인쇄 창·PDF 저장 모두 여러 쪽으로 나눠 출력해 줘.
7. 전송 중 UI 잠금 및 입력·이미지 방어 (#15, #26, #27):
- `sending === true`인 동안 파일 입력, 탭 전환, `바꾸기`, 옵션 버튼을 모두 비활성화해 줘.
- `usePrinterStore.persist.rehydrate()`를 `try/catch`로 감싸 스토리지 차단 브라우저에서도 정상 동작하게 해 줘.
- 사진 선택 시 HEIC 파일은 "HEIC 사진은 지원하지 않아요. JPG/PNG로 바꿔서 골라 주세요."로 안내하고, 초고해상도 이미지(예: 4000만 화소 이상)는 안전하게 리사이즈하거나 안내 문구로 탭 크래시를 막아 줘.
8. 서비스워커 안전성 및 카탈로그 보수화 (#25, #29):
- `sw.js` 캐시 버전을 올리고, 오프라인·배포 직후 동적 `import()` 청크 로딩 실패 시 하얀 화면 대신 "네트워크에 다시 연결하거나 새로고침해 주세요." 안내를 띄워 줘.
- USB `CMD`가 비어 있고 이름만으로 매칭된 복사기(예: PCL 옵션이 없을 수 있는 캐논 iR-ADV 등)는 카탈로그 이름만으로 바로 USB PCL5e에 보내지 말고, `CMD` 확인이 없을 때는 안전하게 OS 인쇄 창을 기본으로 두거나 확인 안내를 거쳐 줘.

[C. 단위 테스트 대폭 보강 (#6, #30)]
9. 기존 4개 테스트 외에 아래 항목을 전부 검증하는 단위 테스트를 추가하고 통과시켜 줘:
- PackBits 128바이트 반복/비반복 경계, `0x80` 미생성, 끝 1~2바이트, 2바이트 반복
- 여러 쪽 `@PJL SET QTY` / 1쪽 `@PJL SET COPIES` 단일 사용 및 `ESC & l n X` 미포함
- 홀수 쪽 양면 시 확정 빈 페이지 패딩 + 완전 백지 최소 1점 래스터 존재
- 매 페이지 `ESC * p 0 x 72 Y`, `ESC * r <w> S`, `ESC * r <h> T`, `ESC * r 1 A`, `ESC * b 2 M` 및 `W` 줄 경계 청킹
- `/Rotate 90`이 이미 적용된 PDF가 180도 뒤집히지 않음
- IPP-over-USB(`protocol=4`)·1284.4(`protocol=3`) 제외 및 `CMD` 조합(`PCL,PCLXL` 등) 분기
- 긴 메모 2쪽 이상 분할

수정 후 전체 단위 테스트 결과, `npm run build` 통과 여부, `.bcmap` 서빙 확인 결과를 보고해 줘.
