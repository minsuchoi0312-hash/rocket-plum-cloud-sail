지금 만든 `office_print` Flutter 앱을 실제 갤럭시탭(안드로이드 14/15/16)과 아이폰, 사무실 복사기에 처음 투입하기 전에 **런타임 크래시·먹통·토너 낭비 사고**를 원천 차단하고 싶어.
추측하지 말고 실제 Dart / Kotlin / Gradle / Info.plist 코드를 끝까지 직접 다시 읽고, 아래 10개 항목을 전부 감사한 뒤 결함이 하나라도 있으면 그 자리에서 전부 수정해 줘.

각 항목마다 반드시 [코드 확인 결과(파일·함수명) → 문제 유무 → 수정 내용] 형식으로 정직하게 보고해 줘.

1. **PDFium(`pdfrx`) 투명 배경 시커먼 출력 방지 & 메모리 해제 (치명)**
- `pdfrx`로 페이지를 렌더링할 때 배경이 투명이면 흑백 변환 시 픽셀 값이 0이 되어 종이 전체가 시커멓게 찍혀. 렌더링 시 흰색(`0xFFFFFFFF`) 배경으로 합성되는지, 채널 순서(`RGBA` vs `BGRA`)가 밝기 계산(`0.3R+0.59G+0.11B`)과 맞는지 확인하고 보장해 줘.
- 모든 `PdfImage` / 픽셀 버퍼가 예외 발생 시에도 `try/finally`로 즉시 `dispose()` 되는지 확인해 줘.

2. **Android 14/15/16 USB 권한 요청 & 리시버 크래시 방지 (치명)**
- `compileSdk 36` 환경에서 `UsbManager.requestPermission`에 넘기는 `PendingIntent`가 `Intent(ACTION_USB_PERMISSION).setPackage(context.packageName)`(명시적 인텐트) + `PendingIntent.FLAG_MUTABLE`로 되어 있는지 확인해 줘. (암시적 인텐트 + `FLAG_MUTABLE`은 안드로이드 14+에서 즉시 `IllegalArgumentException` 크래시 발생)
- `registerReceiver`가 `ContextCompat.registerReceiver(..., ContextCompat.RECEIVER_NOT_EXPORTED)`로 등록되어 `SecurityException`이 안 나는지, 화면 종료 시 `unregisterReceiver`로 누수가 없는지 확인해 줘.

3. **Kotlin USB 전송 메인 스레드 멈춤(ANR) 및 리소스 누수 방지 (치명)**
- Flutter `MethodChannel`의 `onMethodCall`은 안드로이드 UI 메인 스레드에서 실행돼. `bulkTransfer`(15초 타임아웃)나 `GET_DEVICE_ID` 제어 전송이 메인 스레드를 막고 있지 않고, 전용 백그라운드 스레드(`Executors.newSingleThreadExecutor()` 등)에서 실행된 뒤 `Handler(Looper.getMainLooper())`로 결과를 돌려주는지 확인·수정해 줘.
- USB 전송 도중 앱 취소 버튼이 눌렸을 때 Kotlin 쪽 루프도 즉시 중단되도록 취소 플래그를 연동해 줘.

4. **Android mDNS 자동 검색 `MulticastLock` 획득 및 `_ipp._tcp` TXT 활용 (치명)**
- Android에서 `CHANGE_WIFI_MULTICAST_STATE` 권한만 있고 Kotlin에서 `WifiManager.createMulticastLock(...)`을 `acquire()` 하지 않으면 갤럭시탭에서 mDNS 복사기가 0대로 뜰 수 있어. 검색 시작 시 `MulticastLock`을 잡고 검색 종료 시 `release()` 하도록 네이티브 연결해 줘.
- mDNS에서 `_ipp._tcp` 서비스가 잡히면 TXT 레코드의 `ty`(모델명)와 `pdl`(지원 언어: `application/pdf`, `PCL5`, `PCL6`, `URF` 등)도 읽어 와서, 9100 포트 `@PJL INFO ID` 응답이 없는 복사기도 모델명과 PDF/PCL5 지원 여부를 정확히 판별하게 보강해 줘.

5. **Wi-Fi TCP 9100 실제 스트리밍 `flush()` 및 타임아웃·소켓 종료 검증 (치명)**
- Dart `Socket.add(chunk)`만 호출하고 `await socket.flush()`를 안 하면 메모리에만 쌓였다가 진행률이 100%로 가짜 완료되고 실제 타임아웃도 안 먹어. 청크 전송마다 `await socket.flush().timeout(Duration(seconds: 15))`을 걸어 실제 복사기 수신 속도와 진행률·타임아웃이 일치하게 해 줘.
- `@PJL INFO ID` 조회 소켓과 실제 인쇄 소켓을 완전히 분리하고, 조회가 끝난 소켓은 즉시 `destroy()` 해서 복사기가 이전 연결을 붙잡고 다음 인쇄를 거절하는 현상을 막아 줘.

6. **Release APK R8/ProGuard 코드 삭제 크래시 점검 (치명)**
- `android/app/build.gradle.kts`(또는 `build.gradle`)의 `release` 빌드에서 `isMinifyEnabled` / `isShrinkResources` 설정을 확인하고, 난독화가 켜져 있다면 `proguard-rules.pro`에 `MethodChannel`, Kotlin USB 클래스, `pdfrx`, `nsd` 관련 `-keep` 규칙이 빠져 크래시 날 위험이 없는지 점검·보완해 줘.

7. **공유 받기(`ACTION_SEND`) 실전 예외 처리 (높음)**
- 카카오톡, 삼성 내 파일, 구글 드라이브에서 `content://` URI로 공유할 때:
  - 한글 파일명이나 확장자 없는 URI도 MIME 타입(`application/pdf`, `image/*`)으로 정확히 구분해 임시 파일로 복사하는지
  - Android 13+(API 33+)에서 `getParcelableExtra` 호환성 경고가 없는지
  - 앱 실행 시 이전 임시 공유 캐시 파일이 무한히 쌓이지 않게 정리되는지
  - `AndroidManifest.xml`의 `launchMode="singleTop"`과 콜드 스타트(꺼진 상태에서 공유) + 웜 스타트(켜진 상태에서 공유) 둘 다 정상 동작하는지 확인·보강해 줘.

8. **인쇄 중 뒤로가기(`PopScope`)·중복 클릭·에러 복구 (높음)**
- 안드로이드 제스처/하단 뒤로가기 버튼을 인쇄 전송 중(`sending == true`)에 눌러도 화면이 닫히거나 전송이 끊기지 않게 `PopScope(canPop: !sending)`으로 잠그고 안내 스낵바를 띄워 줘.
- `복사기로 바로 인쇄` 버튼 연타 시 두 작업이 동시에 나가지 않게 완벽히 잠겨 있는지 확인해 줘.

9. **PCL6·UFR II 전용 복사기 쓰레기 출력 방지 안전장치 (높음)**
- 사내 와이파이에서 `@PJL INFO ID` 응답도 없고 mDNS TXT `pdl`도 없는 수동 IP 복사기의 경우, PCL5e를 못 알아듣는 기종에 바로 쏘면 깨진 문자가 수십 장 쏟아질 수 있어.
- 언어가 미확인된 수동 IP 복사기일 때는 2단계 확인 화면에서 지원 언어 선택(`PDF 지원` / `PCL5e 흑백` / `잘 모름`)을 보여 주고, 3단계에서 바로 `1쪽 시험 인쇄`로 먼저 정상 출력되는지 안전하게 확인할 수 있게 문구와 흐름을 다듬어 줘.

10. **iOS 빌드 호환성 최종 점검 (높음)**
- `Platform.isAndroid` 가드가 USB `MethodChannel`, `MulticastLock`, Android Share 인텐트 호출 전체를 감싸 iOS에서 `MissingPluginException`이 절대 안 나는지 확인해 줘.
- `ios/Podfile`(또는 iOS 프로젝트 설정)의 최소 버전이 `14.0` 이상인지, `Info.plist`에 `NSLocalNetworkUsageDescription`, `NSBonjourServices` 4종, `NSPhotoLibraryUsageDescription`, 표시 이름 `바로 인쇄`가 빠짐없이 들어 있는지 최종 점검해 줘.
