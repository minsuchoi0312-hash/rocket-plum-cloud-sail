자가진단 내용 중 웹에서 당장 고칠 수 있는 실제 버그 6가지만 한 번에 정리해서 웹앱 버전을 마감해 줘.

1. 72px 여백 잘라내기 → 인쇄 가능 영역 안으로 축소 배치 (#1)
- 전체 용지(2480×3508)에 그린 뒤 사방 72px를 잘라내지 말고, 처음부터 인쇄 가능 영역 크기(A4 2336×3364, A3 3368×4817, B5 2008×2891) 안에 원본 PDF·사진이 안 잘리게 축소 배치(contain)해서 그려 줘.

2. 가로형(Landscape) PDF 자동 90도 회전 (#2)
- PDF 페이지가 가로로 더 길면(`width > height`) 세로 종이 가운데 작게 넣지 말고, 캔버스 렌더링 시 자동으로 90도 회전시켜 세로 A4/A3 인쇄 가능 영역을 꽉 채우게 해 줘. (복사기 가로 용지함 의존 피하기)

3. USB 인터페이스 점유 안내 및 분리 감지 (#3)
- `claimInterface` 실패 시 에러를 삼키지 말고 "다른 앱이나 OS 드라이버가 USB를 사용 중이라 이 앱에서 바로 보낼 수 없어요. 인쇄 창으로 진행해 주세요."라고 정확히 안내해 줘.
- `navigator.usb`의 `disconnect` 이벤트를 구독해서 케이블을 뽑으면 죽은 세션(`sessions`)과 연결 상태를 즉시 정리해 줘.

4. USB 전송 타임아웃 추가 (#4)
- `sendUsbBytes`의 `transferOut`에 15초 타임아웃(`Promise.race`)을 걸어, 용지 없음·걸림 시 영원히 멈추지 않고 오류를 띄우며 중단되게 해 줘.

5. PCL5e 내부 장수 명령 추가 (#5)
- `pclJobHeader`에 `@PJL SET COPIES`와 함께 PCL 본문 장수 명령 `ESC & l <copies> X`도 같이 넣어 구형 복사기에서 1장만 나오는 문제를 막아 줘.

6. PDF 미리보기 반복 오픈 제거 (#6)
- 미리보기에서 쪽을 넘길 때마다 `openPdf()`로 파일 전체를 다시 열지 말고, 같은 PDF 파일인 동안 열린 문서 객체를 유지한 채 해당 쪽만 다시 렌더링해 줘.

수정 후 기존 단위 테스트 + 가로 PDF 자동 회전 / 72px 안 잘림 검증과 `npm run build` 통과만 확인해 줘.
