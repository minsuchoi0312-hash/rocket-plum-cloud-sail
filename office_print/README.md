# 바로 인쇄

사무용 복사기·레이저 복합기용 Flutter 앱입니다. 안드로이드 기본 인쇄 창이나 AirPrint로 넘기지 않고, 앱 안에서 와이파이 TCP 9100 또는 안드로이드 USB로 바로 보냅니다.

## 안드로이드 스튜디오

1. 이 폴더(`office_print`)를 엽니다. `android`만 열지 마세요.
2. 기기나 에뮬레이터를 고르고 Run 합니다.
3. iOS는 Xcode에서 `ios/Runner.xcworkspace`를 엽니다. USB 인쇄는 안드로이드만 됩니다.

최소 버전은 Android 8.0(API 26), iOS 14입니다. Flutter 3.50이 SDK 36을 요구해서 `compileSdk`는 36입니다.
